# Phone Bridge

پروژه سبک Kotlin برای تبدیل گوشی Android به میزبان پنل محلی. آیفون و شیائومی را به یک هات‌اسپات وصل کنید، برنامه را روی شیائومی اجرا کنید و آدرس نمایش‌داده‌شده را در Safari باز کنید.

## قابلیت‌های فعلی
- نمایش و جست‌وجوی مخاطبین شیائومی در آیفون
- شماره‌گیری از پنل
- ارسال SMS
- نمایش تاریخچه تماس‌ها
- نمایش وضعیت تماس ورودی
- پنل بدون اینترنت و بدون سرور خارجی

## ساخت
با Android Studio باز کنید و Run بزنید. مجوزهای Contacts, SMS, Phone را تأیید کنید.

## محدودیت مهم Android/iOS
هات‌اسپات و بلوتوث به‌تنهایی صدای تماس سیم‌کارت را به Safari منتقل نمی‌کنند. این پروژه کنترل تماس و پیامک را انجام می‌دهد؛ انتقال صدای واقعی نیازمند پیاده‌سازی جداگانه WebRTC/VoIP و سرویس تماس پیش‌فرض Android است.
